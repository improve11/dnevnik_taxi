# Дневник смен водителя

Небольшое веб-приложение для учёта поездок водителя. Backend на FastAPI, база SQLite, интерфейс на HTML/CSS/JavaScript.

## Возможности

- Сводка за выбранный день: количество поездок, выручка, комиссия и сумма на руки.
- Разбивка выручки по наличным и оплате картой.
- Список поездок и переключение между датами.
- Добавление поездки через веб-интерфейс и API.
- Проверка суммы, времени, способа оплаты и комиссии.
- Защита от дублей: повтор идентичного запроса с тем же `id` не создаёт запись; тот же `id` с другими данными возвращает HTTP 409.
- SQLite для постоянного хранения данных.
- Автоматическая загрузка `data/trips.json` при первом запуске: уже существующие `id` повторно не добавляются.
- Swagger UI и pytest-тесты.

## Требования

- Python 3.10 или новее (рекомендуется Python 3.12).
- Интернет нужен только для установки зависимостей.

## Запуск локально

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Windows PowerShell

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Откройте в браузере:

- Приложение: http://127.0.0.1:8000/
- Документация API: http://127.0.0.1:8000/docs
- Проверка сервера: http://127.0.0.1:8000/health

При первом запуске приложение создаёт `driver_diary.db` и импортирует примеры из `data/trips.json`. База и записи сохраняются после перезапуска.

## Запуск тестов

```bash
pytest -v
```

Тесты используют отдельную временную SQLite-базу и не изменяют локальную базу разработчика.

## API

### `GET /api/trips?date=2026-10-01`

Возвращает список поездок за дату `YYYY-MM-DD`.

### `GET /api/summary?date=2026-10-01`

Пример ответа:

```json
{
  "date": "2026-10-01",
  "trip_count": 2,
  "revenue": 3900.0,
  "commission": 585.0,
  "take_home": 3315.0,
  "cash": {"trip_count": 1, "amount": 1500.0},
  "card": {"trip_count": 1, "amount": 2400.0}
}
```

### `POST /api/trips`

Пример тела запроса:

```json
{
  "id": "trip-003",
  "start": "2026-10-01T10:00:00+04:00",
  "end": "2026-10-01T10:25:00+04:00",
  "amount": 2000,
  "payment": "card",
  "commission": 300
}
```

`start` и `end` должны содержать часовой пояс. При успешном создании API возвращает HTTP 201. Точная повторная отправка существующей поездки возвращает существующую запись без создания дубля. Если `id` совпадает, а данные отличаются, API возвращает HTTP 409. Невалидные данные приводят к HTTP 422.

### `GET /health`

Возвращает `{"status":"ok"}`.

## Правила расчёта

- Выручка = сумма `amount` всех поездок за день.
- Комиссия = сумма `commission` всех поездок.
- На руки = выручка минус комиссия.
- Наличные и карта суммируются отдельно.
- Дата поездки определяется календарной датой в часовом поясе поля `start`, как в исходном JSON. Время сохраняется в ISO 8601 вместе с переданным смещением.
- Валюта не задаётся, так как исходные данные не содержат валютного поля.
